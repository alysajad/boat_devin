- Keep source code and documentation in this repository.
- Record meaningful milestones in [CHANGELOG.md](CHANGELOG.md).
- Record Devin assistance in [AI_USAGE.md](AI_USAGE.md).
- Retain licenses and attribution for third-party code, fonts, audio, textures and models.
- Do not commit secrets, private keys, tokens or personal credentials.
- Provide a working demo or reproducible local instructions in [SUBMISSION.md](SUBMISSION.md).
- Confirm that the production build and automated checks pass before submission.

## Project-specific safety

Devin Hacks treats phone motion as a game-control signal. Players should hold their phones securely and use comfortable rowing gestures. The project does not measure fitness, medical performance or real boat technique.

Rooms and session tokens are temporary. The server validates controller identity, stroke cadence, timestamps and record permissions. Hosts should restart the server after an event to clear in-memory rooms.
